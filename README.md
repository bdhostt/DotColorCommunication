# DotColorCommunication - Sales, POS & ERP

Enterprise Sales, Point of Sale (POS), Inventory & Supply Chain ERP Solution for **DotColorCommunication**.
Developed & Powered by **BD HOSTT**.

## Features
- **Point of Sale (POS):** Fast barcode/SKU checkout, dual pricing (Factory & Retail), instant cash & digital receipts, discount management.
- **Sales & Orders Management:** Order tracking, production workflow (Prepress, Printing, Finishing, Delivered), delivery challans & tax invoices.
- **Inventory & Multi-Premise Stock:** Factory Production Plant & Corporate Office stock monitoring with low-stock alerts.
- **Supply Chain & Purchase Orders:** Vendor management, PO tracking, procurement expense records.
- **Accounting & Financial Ledger:** Double-entry journal, income & expense heads, customer/supplier dues, Chart of Accounts.
- **Reports & Analytics:** Daily sales, profit & loss, inventory valuation, and GST/VAT tax reporting.
- **Company Profile & Branding:** Dynamic premise customization, service catalog, banking details, and customizable footer credits.

## Tech Stack
- **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Storage & State:** LocalStorage with optional MongoDB Cloud Database sync
- **Backend Sync:** Node.js, Express, MongoDB Atlas

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
